# Guia de Utilização da Plataforma Elastic Security para Análise de Logs

Este repositório contém um guia prático desenvolvido para demonstrar a utilização da plataforma Elastic Security no processo de análise de logs em ambiente web.

O material apresenta, de forma simplificada, as etapas de:
- acesso à plataforma Elastic Cloud;
- criação de ambiente (deployment);
- importação de arquivos de logs;
- visualização dos dados no Kibana;
- identificação de padrões suspeitos e anômalos.

O experimento foi desenvolvido em ambiente acadêmico com dados simulados, tendo como objetivo demonstrar como ferramentas de análise de logs podem auxiliar na identificação de possíveis ameaças cibernéticas, como tentativas de autenticação inválidas e padrões semelhantes a ataques de força bruta.

## Objetivo

Demonstrar, de forma prática e visual, como plataformas de SIEM e análise de logs podem ser utilizadas no apoio à detecção de comportamentos suspeitos em ambientes computacionais.

## Observação

Os dados utilizados no experimento são simulados e o projeto possui finalidade exclusivamente acadêmica.
